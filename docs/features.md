# Paper Shell 功能与使用手册 (User Guide)

Paper Shell（纸壳）是一款专注于中文与长文写作的轻量级桌面编辑器。本文档详细记录了纸壳的各项功能设计、工作原理、高级配置与安全机制。

## 一、专注编辑与文字排版

纸壳将文档置于界面的绝对核心，去除所有花哨的多余装饰。

- **格式支持**：直接编辑纯文本文件，支持 `.txt`、`.md`、`.markdown`、`.text`、`.org` 以及 `.rst`。
- **排版微调**：
  - 点击顶部菜单 **排版**，可直接调整字号（Font Size）、行间距（Line Spacing）、中文字体族、文本颜色与段落首行缩进。
  - 所作排版修改将实时作用于当前文档，并在偏好设置中记住你的习惯。
- **查找与替换**：支持快捷键 `Cmd/Ctrl + F` 进行文本搜索与高亮匹配，支持整词与大小写匹配。
- **未保存保护**：切换文档或关闭窗口时，若有未保存内容会自动弹出确认窗口，防止心血丢失。

## 二、懂中文分词的 Vim 模式

普通文本编辑器的 Vim 模式往往将整段中文文本视为单一无间断字符序列，导致 `w`（向前跳词）直接跳到段尾。

纸壳深度集成了 [Jieba (结巴分词)](https://github.com/messense/jieba-rs) 引擎：

- **模式切换**：通过菜单 **编辑 → Vim 模式 (Esc)** 或在编辑区按 `Esc` 进入 Normal 模式；按 `i`、`a` 或 `o` 回到 Insert 模式。在 Insert 模式下完全不干扰中文输入法的使用。
- **分词感知移动**：
  - `w`、`b`、`e`：按照中文自然语义词边界进行光标跳跃。例如“沉浸在写作之中”会准确按“沉浸”、“在”、“写作”、“之中”跳跃。
  - `dw`、`yw`、`cw`：删除、复制、修改当前中文词语。
- **完整操作符与动作**：
  - 支持常用行移动（`h`, `j`, `k`, `l`, `0`, `$`, `^`, `gg`, `G`）。
  - 支持 Visual 字符与行选择模式（`v`, `V`）。
  - 支持数字计数前缀（如 `3w`, `5dd`）。
  - 剪切板无缝对接系统剪贴板（System Clipboard）。

## 三、类 Git 的文档分支版本历史

纸壳为每篇文档构建了基于内容哈希的本地版本历史树，无需 Git 命令行，普通写作者也能享受版本控制的安全感。

- **内容寻址与哈希树**：
  - 每次保存（`Cmd/Ctrl + S`）时，系统会自动记录文档内容快照，并保留父版本引用。
  - 打开 **文件 → 版本历史…**，即可看到可视化的版本演变树状图。
- **差异对比 (Diff)**：
  - 点击任意历史版本，可查看该版本生成的时间戳、专注写作时长、增删字数，以及与父版本或当前文档的正文 Diff 对比。
- **安全回滚与分支演进**：
  - 回滚（Restore）至某一历史节点不会删除该节点之后的任何保存记录。
  - 从旧版本继续编辑并保存，会自动派生出一个平行的**兄弟分支（Sibling Branch）**。
- **里程碑管理**：
  - 支持对关键节点添加自定义标签（Label）或置顶图钉（Pin）。
  - 当前工作版本及所在分支受保护，不可误删。

## 四、工作区与文件管理

- **侧边栏文件树**：
  - 按 `Cmd/Ctrl + Shift + E` 或点击标题栏的“纸壳”标题，展开或隐藏左侧工作区。
  - 可通过右键添加本地文件夹；自定义文件夹中的文件保存在原位，就地读写。
  - 移除工作区中的文件夹不会删除磁盘上的实际文件。
- **自动过滤**：
  - 智能隐藏不支持的文件格式、隐藏文件（`.` 开头文件）与符号链接，保持工作区纯净。
  - 外部修改文件后，点击侧边栏的“刷新”即可同步最新变动。

## 五、行内批注系统

在长文写作和反复打磨时，记录临时的思考批注至关重要。

- **添加批注**：选中任意文本范围，释放鼠标即可触发浮动操作栏，或右键选择 **添加评论 / 备注**。
- **视觉呈现**：被批注的文本呈现柔和的琥珀色半透明高亮和细下划线，点击即可展开编辑或删除批注内容。
- **非侵入式存储机制**：
  - 批注内容以基于字符偏移量（character-indexed）的元数据形式保存在应用本地数据目录中，**绝不向原始纯文本文件中插入额外标记或专有标签**。
  - 批注锚点能够智能跟随正文编辑与版本历史回溯；若整段被批注文字被删除，对应批注亦会自动清理。

## 六、写作统计与字数度量

- **打开统计**：通过 **文件 → 写作统计…**，或直接点击顶部状态栏的字数统计，即可打开统计分析窗口。
- **统计维度**：
  - 涵盖总字数、新增字数、删除字数、累计专注时长与活跃天数。
  - 支持查看近 7 天、近 30 天、今年或全历史周期，支持按天、按周或按月聚合。
  - 包含 **趋势总览**、**时间明细** 与 **文档统计** 三大视图。
- **计算口径规则**：
  - **汉字统计**：1 个汉字计为 1 个词；英文以空格分隔的非空白连续串计为 1 个词。
  - **基准比对**：统计以保存版本为基准对比增删，而非单纯记录物理按键。导入、粘贴或恢复历史版本均会被准确量化。
  - **专注时长**：基于编辑器在前台的活跃专注计时，未保存的草稿不纳入长期统计。

## 七、外观、皮肤库与社区市场

- **内置经典皮肤**：
  - 经典白纸 (Classic Paper)
  - 古雅羊皮纸 (Warm Parchment)
  - 黑曜石夜 (Obsidian Night)
  - 薄荷清夏 (Mint Breeze)
  - 深海墨蓝 (Deep Sea)
  - 春日樱粉 (Cherry Blossom)
  - 无限地带 · 双人疾驰 (Megazone Ride)
  - 竹林深处 (Bamboo Grove)
  - 盛夏站台 (Summer Platform)
- **外观深度自定义**：
  - 在 **设置 → 皮肤与外观** 中，可微调字体、行距、文本颜色、背景图片、背景透明度、窗口圆角等参数。
- **导入与导出**：
  - 当前调校好的视觉方案可一键导出为 `.toml` 配置或 `.paperskin` / `.zip` 完整安装包。

- **在线皮肤市场**：
  - 打开 **浏览皮肤市场…** 可直接浏览并一键安装来自远端 GitHub 仓库维护的社区主题，支持本地离线预览模板。

## 八、导出、打印与插件扩展

- **格式导出**（**文件 → 导出**）：
  - **PDF 文档 (.pdf)**：生成矢量分页 PDF，采用原生高质量排版渲染、自动分页折行与标准页边距。
  - **HTML 文档 (.html)**：导出独立的自包含 HTML 网页，自带优美的阅读器样式、代码高亮以及自适应明暗主题。
  - **Markdown / 纯文本**：将排版后的纯文本另存至指定磁盘目录。
- **原生打印**：
  - macOS 下支持调用系统原生打印面板，支持自动分页与页面预览；其他平台支持对接系统打印流程。
- **插件系统**：
  - 内置 **Print (打印)**、**Cloud Backup (云端备份)**、**GitHub Publish (发布至 GitHub)** 插件。
  - 打开 **插件 → 管理插件…** 即可启用、禁用或配置插件。
  - 支持编写外部扩展插件（通过在插件目录中放置包含 `plugin.toml` 的文件夹并执行“重新扫描”即可安装）。

## 九、应用安全与自动更新机制

### 1. macOS 首次打开指引 (Gatekeeper)

由于当前个人开源构建版本未加入 Apple 付费开发者证书签名，macOS 可能会弹出安全拦截提示（如“无法验证开发者”或“已损坏”）：

- **解决方法**：
  打开终端（Terminal），执行以下命令移除下载隔离标记：
  ```bash
  xattr -cr /Applications/Paper\ Shell.app
  ```
  或者前往 **系统设置 → 隐私与安全性**，找到底部提示并点击 **仍要打开**。

### 2. 自动检查更新机制

- 纸壳在启动时会在后台安静检查 GitHub Releases 是否有新版本。
- 若有可用更新，菜单栏 **文件 → 关于纸壳** 会显示小红点提示。
- 在关于窗口中可一键选择 **下载更新** 与 **安装并重启**。
- 更新机制会在安装前自动校验安装包的 SHA-256 哈希值，确保安装包完整可信。更新后会自动保留已打开的文档并在重启后恢复。

### 3. 插件与数据隐私安全

- **本地优先**：文档与批注默认存放在本地磁盘，不经过任何第三方服务器。
- **插件权限**：外部插件以宿主进程权限运行且未进行沙箱隔离，请仅安装来源可靠的插件。
- **云备份安全**：WebDAV 凭据和加密主密码仅在本次运行中保留，重启后需重新输入；旧版明文凭据在下次保存配置时移除。非本机 HTTP 地址显示风险提示，新备份省略本地绝对路径；支持 AES-GCM 端到端加密与条件覆盖保护。详见 [安全与升级说明](cloud-backup-security.md)。
