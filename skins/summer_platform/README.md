# 夏日站台

90 年代日漫背景皮肤，使用《听到涛声》（海がきこえる / Ocean Waves，1993）的官方剧照。图片未经 AI 生成或修改。

## 本地试用

在 **设置 → 皮肤与外观 → 导入皮肤…** 中选择本目录的 `skin.toml`。
程序会一并导入同目录的 `background.jpg`，然后应用皮肤。
推送至官方仓库后，也可从皮肤市场刷新并安装。

背景强度 18%，覆盖裁切，编辑区不透明，深灰蓝文字。字号 14、行距 1.5、窗口外边距 12，正文内边距为左 2、右 6、上下 6 个逻辑像素，排版与「侧耳倾听 · 破晓晨曦」一致。可修改 `skin.toml` 的 `background_image_opacity` 后重新导入，以比较背景强度。

打开同目录的 `preview.html` 可看图片与文字的合成示意，它不是应用截图。
