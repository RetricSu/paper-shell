# Paper Shell 皮肤插件仓库 (Skins Repository)

本目录为 Paper Shell 官方皮肤插件仓库。应用内置的皮肤市场默认拉取本仓库的 `skins/` 目录：
- GitHub 仓库: `RetricSu/paper-shell`
- 分支: `master`
- 目录: `skins`

## 目录结构

每个皮肤以独立子目录存在，目录内必须包含 `skin.toml` 描述文件：

```
skins/
├── cyberpunk_neon/
│   └── skin.toml
├── nordic_frost/
│   └── skin.toml
├── retro_amber/
│   └── skin.toml
├── bamboo_grove/
│   └── skin.toml
...
```

欢迎向此目录提交新的皮肤风格！
