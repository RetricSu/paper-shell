# Paper Shell 皮肤插件仓库 (Skins Repository)

本目录为 Paper Shell 官方皮肤插件仓库。应用内置的皮肤市场默认拉取本仓库的 `skins/` 目录：
- GitHub 仓库: `RetricSu/paper-shell`
- 分支: `master`
- 目录: `skins`

## 目录结构

每个皮肤以独立子目录存在，目录内必须包含 `skin.toml` 描述文件：

```
skins/
├── cyberpunk_neon/
│   └── skin.toml
├── nordic_frost/
│   └── skin.toml
├── retro_amber/
│   └── skin.toml
├── bamboo_grove/
│   └── skin.toml
...
```

欢迎向此目录提交新的皮肤风格！

## 古雅信纸示例：尺素 · 梅影

`chisu_letter/` 使用思源宋体、原创宣纸纹理、淡墨梅枝与朱印，呈现克制的中文古典信纸质感。
字体来源、安装说明与浏览器预览见 [皮肤说明](chisu_letter/README.md)。

## 图片背景示例：夏日站台

`summer_platform/` 使用 1993 年《听到涛声》的官方剧照，包含 JPG 背景、配色和排版。
在应用中导入该目录的 `skin.toml` 即可试用，详见 [素材来源和使用说明](summer_platform/README.md)。
升级会将最早默认的 `retricsu/paper-shell-themes · main · skins` 迁移到上述官方源，其他自定义源保留。

## 图片背景示例：无限地带 · 双人疾驰

`megazone_ride/` 使用《无限地带23》省吾载唯骑乘红色摩托的剧照，暖灰底、深色文字与青绿点缀。
背景铺满编辑区，文字保留独立边距。导入方法与素材说明见 [皮肤说明](megazone_ride/README.md)。

## 图片背景示例：侧耳倾听 · 破晓晨曦

`whisper_dawn/` 使用 1995 年《侧耳倾听》官方剧照，远山薄雾与破晓晨光。
背景强度调轻至 18%，文字清澈浮现，内边距与字号行距完全贴合经典白纸。导入方法见 [皮肤说明](whisper_dawn/README.md)。
