## 设计特点

1. **写作者的破晓仪式感**：《侧耳倾听》是一部讲述写作、读书与追寻内心声音的 90 年代经典动画。剧照取自全片高潮——天色微亮的山顶坡道上，圣司与雫一同远眺东京平原，朝阳初升穿透薄雾云海。
2. **轻透背景不抢视线**：背景透明度设为 18%（相比其他主题更轻透），确保正文文字清晰浮现，如同水印般静默衬于纸页之后。
3. **完全继承白纸边距与排版**：严格保留「经典白纸」默认内边距（左 2、右 6、上下 6 个像素）与字号行距（字号 14.0，行距 1.5），无额外 padding 干扰，专注纯粹的书写节奏。
4. **晨光配色系统**：
   - 编辑区与主窗底色：`#F6F4ED`（晨雾微温纸白）
   - 侧边栏与标题栏：`#EBE8DD`（柔和素雅的灰米纸色）
   - 文字颜色：`#182026`（沉稳高对比度的墨黛色）
   - 强调色：`#C2783E`（破晓金赭）
   - 选区高亮：`#D1E0E8`（清澈晨曦天青）

## 本地试用

在 **设置 → 皮肤与外观 → 导入皮肤…** 中选择本目录的 `skin.toml`。
程序会一并导入同目录的 `background.jpg` 并立即应用。

打开同目录的 `preview.html` 可在浏览器中预览合成效果并动态调节背景透明度。
